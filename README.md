# Jaswanth's Portfolio Website

A modern, responsive personal portfolio website showcasing skills, projects, certifications, internship experiences, and contact information with a clean design, smooth animations, and interactive 3D card effects.

## 📁 Site Structure

The portfolio includes the following pages:

- **index.html** - Hero and homepage with featured projects and services overview
- **about.html** - Bio page with personal information, education, and experience
- **projects.html** - Interactive 3D project cards showcasing development work
- **skills.html** - Tech skills organized by category with animated progress bars
- **certifications.html** - Certificate cards with verification links
- **internships.html** - Timeline-based experience details and key learnings
- **contact.html** - Contact form and social media links

## ✨ Features

- **Responsive Design** - Mobile-first approach with smooth layouts across all devices
- **Modern UI/UX** - Clean dark theme with gradient accents and glass-morphism effects
- **Interactive 3D Cards** - Mouse-tracking 3D perspective effects on project cards
- **Smooth Animations** - Scroll-triggered animations and transitions
- **Skill Progress Bars** - Animated skill level indicators
- **Timeline Layout** - Professional experience timeline on internships page
- **Contact Form** - Form validation with user feedback notifications

## 🛠️ Technologies Used

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid, Animations)
- JavaScript (ES6+)
- Font Awesome Icons

## 🚀 Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Navigate through the different pages using the navigation menu

## 🌐 Deployment

This portfolio is configured to deploy automatically to GitHub Pages. 

### Automatic Deployment
- Push changes to the `main` branch to trigger automatic deployment
- The site will be available at `https://jaswanthreddy1322.github.io/Jaswanth_PORTFOLIO/`

### Enable GitHub Pages
1. Go to repository **Settings** → **Pages**
2. Under **Build and deployment**, select **GitHub Actions** as the source
3. The workflow will automatically deploy on push to main
